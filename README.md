# Tournament Platform

Платформа для створення та перегляду турнірів.

## Можливості
- Створення турнірів
- Реєстрація команд
- Live рахунок матчів
- Таблиця результатів
- Ролі: admin / organizer / user
- JWT авторизація

## Розробка
Backend створений на Node.js + Express + SQLite.
Frontend реалізований через HTML, CSS, Bootstrap та JavaScript.
## Запуск

```bash
npm install
cd backend
node index.js
